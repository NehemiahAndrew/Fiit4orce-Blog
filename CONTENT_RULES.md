# Fit4Force Blog - Content Rules for Codex

## File Naming

`_posts/YYYY-MM-DD-short-slug.md`

Example: `_posts/2026-06-21-naf-attestation-form.md`

## Required Front Matter

Every post must include:

- `title`
- `date`
- `last_verified`
- `description`
- `permalink`
- `categories`
- `tags`
- `source`

Use `templates/post-template.md` as the required structure.

## Hard Rules

1. Never pull recruitment facts, including dates, fees, age limits, or requirements, from forums, other blogs, or social media. Use official sources only.
2. Every factual claim about dates, fees, age limits, or requirements needs a `source` field.
3. Never hardcode a year as a permanent fact. Pair time-sensitive content with `last_verified`.
4. If unsure whether information is current, add a TODO comment for human review instead of guessing.
5. The first 2-3 sentences of every post must directly answer the title question.
6. Fit4Force must never be the opening line. Mention it naturally mid-post or in the closing CTA.
7. Use one category and 1-2 tags per post. No exceptions.
